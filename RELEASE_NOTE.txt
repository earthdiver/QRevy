QRevy v0.19.1

QRevy, formerly QR Repair, helps recover damaged QR codes offline on your Android device.

WHAT'S NEW
• Clarified recovery calculation records, execution status, and diagnostic explanations in the app and in the English and Japanese guides.
• Updated the synthetic recovery examples with reproducible priority-assisted list decoding and image-based bullet-hole recovery using priority cells and a single-segment assumption.
• Restored detailed development history after v0.16.0. Existing version tags are retained with identical file contents at each version, but tags after v0.16.0 now point to newly signed commits. Earlier private history is excluded.
• Removed earlier GitHub Releases and their attached downloads. Historical source versions remain available through their tags; v0.19.1 is the new release baseline.

SAVED WORK COMPATIBILITY
The Android app identity and saved-work location are unchanged. Install as an update to keep existing work.
This release writes QRR format version 26 and reads versions 23–26. Earlier files use defaults for settings they do not contain: a 12-bit partial-bit search limit for version 23, mirrored input off for versions 23–24, and a list-decoding extension of +1 for versions 23–25. Other format versions cannot be opened.
QR Repair v0.18.0 writes format version 25 and cannot open work saved or resaved in version 26.

REQUIREMENTS AND LIMITS
• Android 8.0 or later; QR Code Model 2, versions 1–40.
• Model 1, Micro QR, and rMQR are unsupported.
• Check the estimated QR outline, version, and Finder roles before repair. Difficult images may need manual adjustment.
• Importing an image or text matrix automatically saves work. At most 20 items are retained; exceeding the limit deletes the least recently saved work and its source image.

IMPORTANT
Recovery does not guarantee that the result matches the original content. Confidence scores are explanatory measures, not probabilities. Independently verify important information. Recovered web addresses (URLs) never open automatically.
