QR Repair v0.16.2

QR Repair helps recover damaged QR codes that ordinary readers cannot decode. Processing runs entirely offline on your Android device.

GETTING STARTED
1. Import an image, take a photo, or load a QR matrix text file.
2. Rotate, invert, adjust brightness or contrast, and crop as needed. Check the estimated corners, QR version, and black/unknown/white thresholds.
3. Review the positions and roles of the Finder patterns.
4. If needed, edit individual cells: 0 = white, 1 = black, ? = unknown. Use Tentative for uncertain edits and Fixed for values that recovery should preserve.
5. Tap Repair, then inspect the decoded content, alternative candidates, and explanations for repaired cells.

WHAT'S NEW
• Choose a per-block partial-bit search / dimension limit of 12, 13, or 14 bits (default 12). Each added bit doubles the maximum enumeration count; memory and combination limits still apply.
• Configure priority (*) search for up to 14 cells (default 4), follow assignment progress, and interrupt recovery while retaining candidates already found.
• Review candidate counts and search completion separately. Diagnostics distinguish unmet input conditions, rejected candidates, unfinished work, and omitted candidate details; completing a bounded search does not establish uniqueness.
• Inspect input provenance and format-bit roles, highlight related ECC/mask/correction cells, and compare before/after QR cells with the mask removed.
• Use priority assignments for a single-segment header hypothesis when appropriate. Diagnostics explain whether the single-segment assumption was applied.
• Saved work now uses QRR schema 24. Only schemas 23 and 24 can be opened; schema 23 uses the default 12-bit partial-bit limit. Earlier schemas cannot be reopened, and sessions in the old storage location are not migrated.
• Adjust brightness and contrast in the crop editor, enter numeric values, reset adjustments, and compare before/after views. Adjustments are preserved in saved work.
• Improved inverted-QR detection, fallback corner estimation, settings navigation, and handling of cancelled or superseded recovery work.
• Additional-segment diagnostics skip consecutive zero terminators while preserving ECI and FNC1 context. This analysis does not validate a rejected candidate.

USEFUL FEATURES
• Undo/Redo, detailed cell diagnostics, and recovered-image export.
• Save work without running recovery, and resume it from Saved work (Recent work in Classic).
• English/Japanese interfaces and Classic/Modern layouts.

REQUIREMENTS AND LIMITS
• Android 8.0 or newer.
• Supports QR Code Model 2, versions 1–40.
• Model 1, Micro QR, and rMQR are unsupported.
• Strong perspective distortion is not supported.
• Imports automatically save work. At most 20 sessions are retained; exceeding the limit deletes the least recently saved work and its source image.

IMPORTANT
Recovery does not guarantee that the result matches the original content. Confidence scores are heuristics, not probabilities. Independently verify important information. Recovered URLs never open automatically.
