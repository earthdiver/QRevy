# QRevy ユーザーガイド

[English](USER_GUIDE.en.md) | 日本語

AndroidアプリでQRコードを読み込み、調整、修復、保存する方法を説明します。QRコードを構成する正方形一つを、アプリでは**セル**と呼びます。QR規格での名称はモジュールです。

修復結果が元の内容と一致する保証はありません。重要な情報は、利用する前に別の資料や手段でも確認してください。

## 1. 入力する

| 入力 | 開き方 |
| --- | --- |
| 画像ファイル | **画像を読み込む**または**画像を選択**から、写真やスキャン画像を選びます。画像に記録された向きは自動で反映されます。 |
| カメラ | **カメラ**または**カメラで撮影**を選び、カメラへのアクセスを許可して撮影します。切り抜く範囲を確認し、**クロップして解析**を選びます。 |
| テキスト行列 | **テキスト行列を読み込む**または**TXT行列**を選びます。1文字が1セルを表し、`0`・`1`・`?`・`*`を使えます。[行列テンプレート](../templates/text-matrices/README.ja.md)を使うと、必要な書式と大きさを保てます。 |

QRコード全体と周囲の白い余白が入り、セルの中心がはっきり見える画像を使ってください。透明部分は、表示・解析ともに白い背景として扱います。

読み込むと、作業と元画像が自動保存されます。保存数の上限は[保存、再開、出力](#7-保存再開出力)を参照してください。

## 2. 画像と格子を調整する

クラッシックでは**修復する**を選んで設定を開きます。モダンでは**01 修復設定**を使います。

1. 必要に応じて画像を回転し、切り抜く範囲を決めます。範囲の角や辺をドラッグすると大きさを、内側をドラッグすると位置を変えられます。
2. **画像調整**から**コントラスト**や**明るさ**を調整し、必要なら**白黒反転**を使います。各項目のメニューで数値入力やリセットができます。**調整前**で色調を比較しても、切り抜く範囲や回転は変わりません。解析には調整後の画像を使います。**完了**はスライダーを閉じます。
3. **QRバージョン**を確認し、オレンジ色の角を最も外側のセルの中心に合わせます。バージョン1は一辺21セルで、バージョンが一つ上がるごとに4セル増えます。
4. プレビューのセル値を確認します。損傷箇所が確定した`0`や`1`として読み取られている場合は、白・不明・黒を分ける閾値を調整します。

自動推定は修正が必要な場合があります。輪郭だけが表示されたら、現在の値が正しくても**QRバージョン**を選び直すと格子が表示されます。角を調整し、次節の方法でFinderの役割を割り当ててください。**選択範囲を正方形に射影補正**を使うと、Finderの役割と向きが解除されるため、再度割り当てが必要です。

画像の読み込み時は**閾値を自動設定**が有効で、格子が変わると閾値を再計算します。スライダーを動かすと手動に切り替わり、チェックを外すだけなら現在値を維持します。手動の閾値は、角の調整やサンプリング位置の微調整では変わりません。再計算するにはチェックを入れ直してください。保存した作業では、自動・手動の選択と値が復元されます。

読み取りが不安定なセルも`?`になることがあります。手動編集は画像からの読み取りに優先します。検出された色付きの損傷を不明として扱う場合に限り、**自動検出された色クラスタを不明領域（?）として扱う**を有効にしてください。初期状態は無効で、色クラスタが検出された場合だけ使用できます。

## 3. Finderの役割を確認する

QRコードの隅にある三つの大きな四角形は、**位置検出パターン（Finder）**です。アプリでは**Finder**と表示します。役割はQRコードを正しい向きに置いたときの位置を表し、写真上の位置とは異なる場合があります。

画像やテキストの読み込み時に、役割が自動で割り当てられることがあります。緑色のFinderマーカーを確認してください。**修復には少なくとも一つの役割の割り当てが必要です。**

- 割り当てるには、**左上**・**右上**・**左下**から役割を選び、対応するパターンの中心をタップします。近くにパターンが検出されると、位置が補正されます。
- 間違った役割を取り消すには、**解除**を選んで緑色のマーカーをタップします。すべて解除すると向きも未設定になりますが、角とセル編集は残ります。修復前に役割を再度割り当ててください。
- 隠れたFinderを割り当てる必要はありません。役割を誤ると修復できないことがあるため、確認できるものだけを割り当ててください。

Finderから白黒の反転が判定できた場合、その判定が**自動**・**通常**・**反転**の指定に優先します。判定できない場合は、この指定に従って画像を読み取ります。手入力したセル値は変わりません。

## 4. セルを編集する

クラッシックでは**セル編集（長押し）**を長押しします。モダンでは**セル編集**または**02 セル編集**を選びます。セルをタップしてから値を選び、矢印ボタンで隣のセルへ移動できます。

| 値 | 意味 |
| --- | --- |
| `0` | 論理値の0。通常の白黒の解釈では白 |
| `1` | 論理値の1。通常の白黒の解釈では黒 |
| `?` | 不明。確実に読み取れないセルに使う |
| `*` | 不明のまま、修復時に`0`と`1`の両方を優先して試す |

| ツール | 操作 |
| --- | --- |
| **▱** | ドラッグして四角い範囲を選び、選択したセルの値や指定方法を選びます。 |
| **0ブラシ**・**1ブラシ**・**?ブラシ** | セルをなぞって、対応する値を入力します。 |
| **? 5×5** | タップした位置の周囲5×5セルを不明にします。 |
| **1セル** | 1セルずつの選択に戻ります。 |
| **Undo / Redo** | 編集を元に戻す／やり直します。 |

選んだ値をどのように扱うかを指定します。

| 指定方法 | 効果 |
| --- | --- |
| **画像から判定** | 編集を取り消し、現在の設定で画像から読み取ります。 |
| **仮指定（訂正可）** | 入力値を使いますが、修復時の訂正を認めます。 |
| **固定（訂正不可）** | 初期設定では、入力した`0`や`1`と矛盾する復元候補を除外します。 |

画像から読み取った値を別の`0`や`1`に変えた場合や、`?`・`*`を`0`・`1`に変えた場合は固定になります。確信がない値は、入力してから**仮指定（訂正可）**を選んでください。仮指定済みの`0`・`1`を変更した場合は仮指定のままです。編集を取り消すには**画像から判定**を選びます。画像と同じ値を入力し直しても編集は取り消されません。不明な値は固定できません。

水色の実線の四角は固定、破線の四角は仮指定、黄色い丸は選択中のセルを示します。**指定セルを強調**は表示だけを変えます。編集は閾値を変えても、作業を保存して開き直しても保持されます。

**詳細設定**の**固定セルの0/1と矛盾する復元候補を許容する（仮指定セルと同じ扱い）**は、初期状態では無効です。有効にすると、入力値と固定の指定を保持したまま、修復時の訂正を認めます。無効に戻すと再び保護します。誤り上限、明示的に選んだバージョン・誤り訂正レベル・マスク、および固定セルと明示的な選択との整合性チェックは引き続き適用されます。

### `*`による優先探索

誤り訂正符号（**ECC: Error Correction Code**）のデータは、損傷したQR内容の修復に使います。`*`を指定できるのは、角と向きが設定された後のデータ・ECCセルだけです。Finderパターンや形式情報などの構造を示すセルには指定できません。選択範囲に指定できないセルが一つでも含まれる場合、その範囲への変更は行いません。

**詳細設定**の**優先探索のセル数上限**は4～14セルで、初期値は4です。指定が1セル増えるごとに試す値の組み合わせが倍になり、修復時間が大きく延びる場合があります。上限を下げても既存の指定は残ります。上限を超えた場合は、指定を減らすか上限を上げてから修復してください。テキストから読み込んだ指定にも同じ上限が適用されます。

向きを変えると、データ・ECCセルではなくなった位置の`*`だけが解除され、値は`?`のまま残ります。バージョンを変えると、確認後にすべてのセル編集が消去されます。

## 5. 詳細設定を選ぶ

**詳細設定**を開きます。まず初期設定で試し、プレビューや結果を見て必要な項目を変更してください。QRの誤り訂正には**リード・ソロモン（Reed–Solomon、RS）符号**を使います。コード語は8ビットのまとまりで、ブロックはまとめて訂正するコード語のグループです。

誤り訂正レベルやマスクが分かっている場合は、修復設定の**ECC: 自動**や**mask: 自動**から指定できます。不明なら**自動**のままにしてください。

| 設定 | 使う場面と注意点 |
| --- | --- |
| **サンプリング位置を自動微調整する** | 角はおおむね合っていても、セルの中心から読み取り位置がずれていそうな場合に使います。選んだバージョンと向きを保ちながら、処理が増えます。 |
| **部分bit探索・自由度の上限** | RSブロックごとに12・13・14ビットから選びます。初期値は12です。1ビット増えるごとに、試せる組み合わせの最大数が倍になります。 |
| **通常RSからの追加探索上限** | ブロックごとに+1・+2・+3コード語から選びます。初期値は+1です。上限を上げると大幅に時間が延びる場合があり、候補が増えるとは限りません。 |
| **入力画像を鏡像として処理する** | 鏡に映したようなQR画像で使います。右上と左下のFinderの役割が入れ替わりますが、画像の表示は変わらず、編集も画像上の同じセルに残ります。初期状態では無効で、作業ごとに保存されます。 |

探索には時間とメモリの上限もあります。設定値を増やしても、すべての組み合わせを調べられるとは限りません。

### 誤り上限

**形式情報の誤り上限**は、誤り訂正レベルとマスクを示す既知セルとの不一致を制限します。**データ・ECCの誤り上限**は、既知のデータ・ECCセルとの不一致を制限します。不明セルは数えません。小さくすると厳しくなりますが、入力の読み間違いが多いと正しい結果も除外する場合があります。

どちらも**初期設定**・**完全一致（0bit）**・**厳しめ**・**緩め**・**手動**・**制限なし**から選べ、実際のビット数が表示されます。数値の編集や±ボタンの使用で手動に切り替わります。**適用**で確定してください。

プリセットはバージョン変更時に再計算されます。手動は入力値を保持し、範囲外になった場合は有効な値の再入力が必要です。完全一致では、比較対象の既知セルすべてとの一致を求めます。比較から除外するセルは[修復結果の見方](RECOVERY_RESULT_FIELDS.ja.md#入力との一致とqr設定)を参照してください。制限なしでも、固定セルの保護や明示したQR設定は適用されます。

リスト復号は、通常のRS訂正の範囲を超えて候補を探します。この処理では、既知のデータ・ECCビットとの不一致を、データ・ECC総ビット数の5%（切り上げ）と指定した誤り上限の小さい方に制限します。データ・ECCの誤り上限が0の場合は、リスト復号を行いません。

### 単一セグメントの仮定

セグメントは、一つの符号化方式で続けて記録されたQRデータのまとまりです。**種類・文字数／バイト数を読み取り、または \* の試行で仮定できる場合に…**で始まる設定は、数字・英数字・バイト・漢字のいずれか一つのセグメントだけがあると仮定します。診断では**単一セグメントの仮定**と表示されます。

この構造だと分かっている場合だけ有効にしてください。宣言された個数でデータが終わるものとして、それ以降の矛盾する読み取り値を置き換えることがあります。種類と個数は、読み取れるか`*`の試行で仮定できる必要があります。複数のセグメント、複数のQRコードに分割した内容（**連結QR：Structured Append**）、追加の制御情報が必要なデータには使わず、不明なら無効のままにしてください。

## 6. 修復して結果を確認する

クラッシックでは**設定を保存して修復**、モダンでは**修復**を選ぶと、現在の作業を保存して修復を始めます。**保存**は作業の保存だけを行います。

**検証済み候補**は、QR構造の確認と指定した入力条件を通過した候補ですが、内容の復号に失敗する場合もあります。

進捗画面には経過時間が表示されます。**修復を中断**で処理を止めても、見つかった検証済み候補は残ります。リスト復号の上限は**修復1回につき累計10分**で、通常の探索時間は含まないため、全体ではさらに時間がかかる場合があります。時間切れやメモリ不足で終了した場合も、検証済み候補は残ります。

1. 復号された内容を読みます。複数の候補がある場合は**候補の内容一覧**で全文を比較し、選びたい候補の本文をタップします。
2. **診断情報を表示**から、入力との不一致、探索の完了状況、候補の省略を確認します。候補が一つだけ、または探索が完了していても、正しい結果だと確定はできません。
3. **詳細結果を表示**でセルをタップし、値や理由を調べます。**同じコード語を表示**は、同じコード語に属するセルを強調します。**データ**ではビットと16進数（**HEX**）を確認できます。

判定や項目の意味、セルの色、比較例は[修復結果の見方](RECOVERY_RESULT_FIELDS.ja.md)、探索の順序や各方式の適用条件は[QRevyの修復の仕組み](RECOVERY_STRATEGY.ja.md)を参照してください。

**マスク解除**は表示だけを変え、保存するQR画像は変えません。失敗した試行でマスクが確認できない場合は、表示が変わらないことがあります。元の表示に戻すにはチェックを外してください。

診断の下に**終端後の追加セグメントを解析**が表示された場合は、構造の確認に失敗したデータについて、QRの終端を示す情報より後を調べられます。提示された開始位置を選んで解釈を比較してください。**終端後の生データを表示／閉じる**では、終端直後・次のバイト・指定したビット位置から生のビットを表示できます。この確認で、元の試行や追加の内容が検証済みの修復結果になるわけではありません。

## 7. 保存、再開、出力

読み込み時と修復開始前に自動保存されます。保存できる作業は**最大20件**です。上限を超えると、最後に保存した日時が古い作業から元画像とともに削除されます。起動時の整理でも同じ上限が適用されます。

**作業一覧**または**最近の作業**で項目をタップすると再開できます。長押しで1件を削除し、**すべて削除**で一覧を消せます。画面で開いている作業を一覧から削除しても、その画面では作業を続けられます。その後に保存すると、新しい作業として保存されます。

**操作履歴**は**最大40状態**で、メモリやファイル容量の上限により少なくなる場合があります。古い状態が整理されても、選択中と最新の状態は保持されます。修復後の状態を再開すると、候補を再計算します。以前の候補が見つからなければ、結果を未選択にして理由を表示します。

### 保存した作業の互換性

QRRはアプリの作業保存形式です。保存には形式の版番号**26**を使い、**23～26**を読み込めます。それ以外は読み込めません。古いファイルに保存されていない設定は、次の値で復元します。

| ファイルの版番号 | 復元時の初期値 |
| --- | --- |
| 25 | 通常RSからの追加探索上限：+1 |
| 24 | 通常RSからの追加探索上限：+1、鏡像としての処理：無効 |
| 23 | 通常RSからの追加探索上限：+1、鏡像としての処理：無効、部分bit探索・自由度の上限：12 |

### 出力とプライバシー

**内容をコピー**は、復号された全文を端末のクリップボードへ送ります。**PNG保存**は、選択した検証済みQR候補をPNG（Portable Network Graphics）形式の画像として出力します。失敗した試行は、修復済みQRとして出力できません。

保存した作業はアプリ専用の領域に置かれ、Androidのバックアップと端末間転送の対象外です。アプリによる暗号化は行いません。出力した画像はアプリ専用領域の外に保存されるため、出力先の共有・バックアップ設定を確認してください。[プライバシー](../PRIVACY.ja.md)と[セキュリティ](../SECURITY.ja.md)も参照してください。

## 8. 画面スタイルとナビゲーション

- **メニュー → 言語 / Language**で日本語か英語を選べます。未保存の場合は、端末の言語が日本語なら日本語、それ以外なら英語になります。
- **メニュー → 画面スタイル（次回起動時）**でクラッシックかモダンを選び、保存します。初期設定はクラッシックです。次回起動時に反映され、画面回転や言語変更では切り替わりません。
- モダンには**01 修復設定**・**02 セル編集**・**03 修復結果**があります。結果があると結果タブを開けるようになり、次の修復まではその結果を表示します。

タブの切り替えや画面回転でも、未保存の設定・セル編集・Undo/Redoの履歴は保持されます。保存するには**保存**または修復を実行してください。設定から離れるときは、未保存の変更を破棄する前に確認が表示されます。
