| ![欠損セルと2bitの誤り](before.png) | ![修復後のQR](after.png) | ![補完セルは青、訂正セルはオレンジ](details.png) |

独自に生成したこのQRには、441セル中53セル（12.0%）の欠損と、既知のデータセルに2bitの誤りがあります。[記録された結果](result.json)では、すべてのセルが元のQRに一致する候補が1つ得られ、次のテキストを復元できました。

```text
QRevy repaired.
```

## 試す手順

「テキスト行列を読み込む」で[before.txt](before.txt)を開き、**単一セグメントの仮定**をONにします。記入済みの`*`を保ち、Finderの役割を確認して「修復」を実行してください。バージョンは入力から決まる1です。ECC・マスクは自動のままにします。修復後のQRはECC L・マスク0です。

それ以外の探索設定は初期値のままです。

| 設定 | 値 |
| --- | --- |
| フォーマットbitの誤り上限 | 自動（6bit） |
| データ・ECCの誤り上限 | 自動（バージョン1では2bit） |
| 優先探索のセル数上限 | 4（この入力で使うのは1セル） |
| 部分bit探索・自由度の上限 | 12bit |
| 通常RSからの追加探索上限 | ＋1語／RSブロック |

[before.png](before.png)を画像として読み込むこともできます。しきい値の自動設定と初期化された外周・バージョン・向きを保ちます。「セル編集」で、最下段の右端から2番目のセル（1から数えて20列・21行）を選び、`*`を指定してください。**単一セグメントの仮定**をONにし、必要ならFinderの役割を確認して「修復」を実行します。PNGにはテキスト行列の優先探索指定は含まれません。操作は[ユーザーガイド](../../USER_GUIDE.ja.md)を参照してください。

修復箇所の画像では、補完した53セルを青、訂正した既知の2セルをオレンジで示しています。既知セルの訂正位置は20列・10行と18列・17行です。

## 三つの方法が必要な理由

優先探索セルは、種類を示すヘッダーの不明な1bitです。仮置きにより単一セグメントの仮定を適用できるようになります。この値は画像の観測ではなく仮説です。仮定により、終端・境界合わせ・パディングの欠損20bitを補完します。その後もECCの4語が丸ごと不明で、ペイロードの2語にはそれぞれ1bitの誤りが残ります。通常の誤り・消失RS訂正に必要なECCは`2 × 2 + 4 = 8`語となり、このQRの7語を超えます。Wuリスト復号は、通常の半径1から1語広げた半径2で、既定の2bitの誤り上限を守りながら元のQRを復元します。

同じ入力と既定の探索上限で比較した結果です。

| 条件 | テキスト行列の候補 | PNGの候補 |
| --- | --- | --- |
| 優先探索＋単一セグメント仮定＋リスト復号 | 元と一致する1件 | 元と一致する1件 |
| 単一セグメント仮定OFF | 0件 | 0件 |
| リスト復号の段階を意図的に無効化 | 0件 | 0件 |
| 優先探索の指定を解除 | 0件 | 0件 |
