# 修復例：複数の貫通穴

| 修復前 | 修復後 | 補完箇所 |
| --- | --- | --- |
| ![不規則な9つの貫通穴があるQR](before.png) | ![実際の修復結果](after.png) | ![補完したセルを青色で表示](details.png) |

**56.8%欠損した合成QRから、元の内容と一致する1候補を取得。**

```text
QR Repair: recovered QR.
```

設定：Version 3／Mの[TEXT行列](before.txt)を入力。単一セグメント仮定ON、冒頭のモード指示子4 bit・バイト数1 bitを `*` に指定、データ・ECCのbit差異上限0、部分bit探索上限12。

全841セル中478セルが未知です（機能パターン等145セル、データ・ECC 333セル）。欠損率はQR本体のセル中心で数えています。修復前は欠損の説明画像、補完箇所は結果の可視化です。実際の修復コード語から修復後の画像を描画し、元の行列・全文との完全一致を確認しました。通常リーダー（ZXing-C++／ZXing Java）では修復前は復号不可、修復後は復号可能でした。

現行コアをデスクトップの評価ハーネスで実行した合成例です。一部計算には未解決診断が残るため、1候補の取得は数学的な一意性の証明ではありません。

[詳細結果・生成条件](result.json) · [入力行列の表示](input-matrix.png) · [生成スクリプト](../../../scripts/generate-bullet-hole-example.py)

生成にはPillow 11.3.0、qrcode 8.2、zxing-cpp 3.1.1と、別途用意するローカルのQR Repair評価実行ファイル（`--harness`）、StandardReaderのJavaクラスパス（`--java-reader-classpath`）を使います。画像と生成コードは独立作成したプロジェクト素材で、リポジトリのライセンスに従います。
