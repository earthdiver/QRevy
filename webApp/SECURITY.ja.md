# セキュリティ

[English](SECURITY.md)

修復候補が得られても、元の内容と一致する保証はありません。重要な情報は別の手段でも確認してください。復号した内容は文字として表示し、含まれるアドレスを自動で開くことはありません。

作業ファイルは読み込み時に形式と整合性を確認しますが、これによって提供者や内容の真正性が保証されるわけではありません。QRRに元画像を追加する場合は、対応する画像か確認してください。

配信にはHTTPSを使い、同梱の `dist/_headers` または同等の設定を配信先に適用してください。ブラウザーとOSを最新の状態に保ってください。

公開の不具合報告には秘密のQRコードや写真を含めず、問題を再現できるサンプルを用意してください。保存データの扱いは[プライバシー](PRIVACY.ja.md)を参照してください。
