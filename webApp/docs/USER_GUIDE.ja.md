# QRevy PWA ユーザーガイド

日本語 | [English](USER_GUIDE.en.md) | [README](../README.ja.md)

QRevy PWA（Progressive Web App：ブラウザーからインストールできるウェブアプリ）は、損傷したQRコードの画像や読み取り値を調整して、内容の復元を試みるアプリです。QRコードを構成する小さな正方形を、このガイドでは画面の表示に合わせて**セル**と呼びます。規格上の名称はモジュールです。対象はQRコード Model 2のバージョン1～40です。

修復候補が得られても、元の内容と一致する保証はありません。重要な内容は別の手段でも確認してください。

## 1. アプリを開く

iPhone・Android・パソコンで、配信されたHTTPSのアドレスをブラウザーで開きます。インストールせずに利用できます。ホーム画面やアプリ一覧から起動したい場合は、次の操作を行います。

| 端末・ブラウザー | インストール方法 |
| --- | --- |
| iPhone・Safari | **共有 → ホーム画面に追加**を選びます。 |
| Android・Chrome | メニュー内のインストール項目を選び、画面の案内に従います。 |
| パソコン・Chrome | アドレスバーのインストールアイコン、またはメニューの**キャスト、保存、共有 → ページをアプリとしてインストール**を選びます。 |

メニュー名やインストールの可否はブラウザーによって異なります。詳しくは[Androidの手順](https://support.google.com/chrome/answer/9658361?hl=ja&co=GENIE.Platform%3DAndroid)・[パソコンの手順](https://support.google.com/chrome/answer/9658361?hl=ja&co=GENIE.Platform%3DDesktop)を参照してください。パソコンでは、このガイドの「タップ」は「クリック」と読み替えてください。

**メニュー → ヘルプ**で**オフライン準備完了**を確認してから通信を切ってください。初回の読み込みと更新には通信が必要です。

画面上部の**English / 日本語**で言語を切り替えます。**メニュー → ヘルプ → 画面スタイル（次回起動時）**でクラッシック／モダンを選べます。同じメニューからバージョン、ライセンス、プライバシーを確認できます。

初めて使う場合は**損傷したサンプルで試す**を選び、入力、セル編集、修復結果の順に操作できます。

## 2. 入力する

画面上部の**メニュー → ホーム**から、画像や作業を選びます。修復結果からも移動でき、現在の作業は保持され、**現在の作業に戻る**で直前の画面へ戻れます。保存済みの作業は**保存した作業を開く**から選べます。

| 入力 | 操作 |
| --- | --- |
| 写真・スキャン画像 | **画像を選択**でファイルを選びます。 |
| カメラ | **カメラで撮影**で撮影します。カメラの利用可否や選択画面は端末・ブラウザーによって異なります。 |
| テキスト行列 | **TXT行列**でテキストファイルを選ぶか、**テキスト行列を貼り付ける → テキスト行列を読み込む**を使います。 |
| 保存した作業 | **作業ファイル**で `.qrpwa` または `.qrr` ファイルを開きます。 |

画像はQRコード全体と周囲の余白が写り、各セルを見分けられるものを使います。切り抜き画面では角や辺をドラッグして範囲を変え、範囲内をドラッグして移動し、**クロップして解析**を選びます。回転、明るさ、コントラスト、白黒反転も調整できます。**調整前**は色調の比較用で、適用する調整を取り消しません。

初期範囲は検出したQRコードと周囲の余白に合わせ、検出できない場合は画像全体になります。解析解像度は初期範囲と選択範囲の大きい方を基準とし、範囲を狭めたときの解像度の変化を抑えます。

テキスト行列は1文字を1セルとして、`0`・`1`・`?`・`*`だけを並べます。各行の文字数と行数を同じにします。バージョン1なら21文字×21行、バージョン2なら25文字×25行です。空白や区切り記号は入れません。

テキスト行列を画像として調整したい場合は**画像として調整（新しい作業）**を使います。元の行列を画像にし、手動編集を引き継ぎます。元の作業も保存され、**メニュー → 保存した作業を開く**から再開できます。

### 簡易自動修復

入力欄の**簡易自動修復**は初期状態で有効です。設定は次回起動時も保持され、以後の画像・カメラ・TXT行列の読み込みに適用されます。画像・カメラ入力では、先にQRコードの通常読み取りを試します。成功した場合はコピーと詳細解析の操作がある文字列の結果を表示し、修復候補としては扱いません。同じ作業を開いている間は「通常読み取りの結果」ボタンで再表示できます。通常読み取りに失敗した場合は、短時間の自動修復を試します。簡易自動修復を無効にすると、読み取れなかった入力は修復設定で開き、格子や条件を確認してから修復できます。

処理中に**詳細解析**を選ぶと、自動修復を中断して格子やセルを調整できます。画像から読み込んだ場合は、画像表示で開きます。読み込み中の場合は、必要な読み込みが終わってから移ります。

| 結果 | 次の操作 |
| --- | --- |
| 完了した試行で候補が1件に絞られた | 内容と適用条件を確認し、必要なら詳細解析へ進みます。 |
| 修復できなかった | 理由を確認し、詳細解析で格子やセルを見直します。 |
| 時間切れ | 10秒の再試行を選べます。 |
| 10秒の再試行も時間切れ | 時間制限なしの再試行を選べます。この後は再試行ボタンを表示しません。 |

再試行は同じ入力から始まり、利用できる格子を引き継ぎます。時間制限なしでも、メモリー不足などで停止する場合があります。結果を1件に絞れなくても、保持された候補は修復結果から確認できます。詳細設定を変更しても、結果に記録された自動修復の実行条件は変わりません。

必要な場合は、読み込み前に**簡易自動修復の診断を記録**を有効にします。**修復結果 → 簡易自動修復の診断**で各試行の記録を確認し、**診断をコピー**でコピーできます。

## 3. 画像と格子を調整する

### バージョンと四隅

1. **画像**表示にし、**QRバージョン**を確認します。バージョン1は1辺21セルで、バージョンが1増えるごとに4セル増えます。
2. **Finderの位置と役割を指定**を**役割を選択**に戻し、オレンジ色の点を最外側のセルの**中心**に合わせます。QRコードの外縁や余白の角ではありません。
3. 細かい位置は**四隅の拡大調整**で調整します。対象の角、移動量を選び、矢印で動かして**適用**を押します。キャンセルすると、この画面での変更を破棄します。
4. **セル**表示に切り替え、格子が画像のセルに合っているか確認します。

**＋ / −**で拡大・縮小し、**移動・拡大**で画像を動かします。タッチ操作では2本指でも拡大・移動できます。**全体**で全体表示へ戻します。

バージョンを手動で選ぶ手がかりは、画像上に重なる**Finderとタイミングパターンのガイド**です。Finderは3隅にある大きな四角い位置検出パターン、タイミングパターンはFinderの間に続く白黒交互の列です。ガイドの大きさ・位置と交互のセルが画像に合うように、バージョンと四隅を調整します。向きが未確定の間は4隅に仮のFinderガイドが表示されます。画像が欠けている場合、ガイドだけでバージョンを確定できるとは限りません。

**バージョンの変更はセル編集を解除します。** セルを編集する前に確認してください。**格子を自動推定**の結果も、画像と照合して調整します。

### Finderの役割と向き

**Finderの位置と役割を指定**で左上・右上・左下を選び、対応するFinderの中心をタップします。この役割は写真の向きではなく、QRコードを正しい向きに置いたときの位置です。

Finderの中心位置を確定した角は緑色で移動が保護され、オレンジ色の角は移動できます。緑色は読み取りの確かさを表しません。中心を検出できない場合も、推定済みまたは手動調整済みの格子があれば役割だけを指定でき、角は移動できます。確認画面が出た場合は内容を確認して適用します。キャンセルすると元の状態を保持します。

役割を選び、**選択したFinderを解除**で測定済みの中心を、**位置未測定の役割指定を解除**で役割だけの指定を解除できます。**Finderの指定 → Finder指定をすべて解除**はすべての指定を解除します。

必要なら**右90°**や**入力画像を鏡像として処理する**で向きを直し、正しい向きになっていることを確認します。向きは自動推定またはFinderの役割指定で確定します。すべての指定を解除した場合は、少なくとも一つの役割を指定し直してください。向きが未確定のままでは修復できません。

修復設定とセル編集では、画像直下の**判定**に現在の `1`・`0`・`?`・`*` の個数を表示します。

### 色調と読み取り

**画像の追加調整**で明るさ、コントラスト、白黒の解釈を調整します。閾値は画像の下の**白黒の読み取り**で指定します。白黒が逆のコードには**白黒判定 → 反転**を使います。

**閾値を自動設定**は初期状態で有効です。閾値は白・黒・不明を分ける境界です。スライダーまたは数値入力で指定できます。数値は0～255の画像の明るさです。通常の白黒では**黒の上限 < 白の下限**にします。例えば黒の上限96、白の下限160なら、その間の明るさを不明として扱います。値を変更すると自動設定は解除されます。黒と白の境界が重なる場合は、もう一方の値も調整されます。白黒が反転した画像では、QRの黒に対応する数値が白より大きくなり、数値とスライダーの増減方向も逆になります。Finderで白黒が確定している場合は、その判定が優先されます。手動で指定したセルは画像の読み取り値より優先されます。

色の付いた損傷を不明にしたい場合は、色のまとまりが検出されたときに**自動検出された色クラスタを不明領域（?）として扱う**を有効にします。格子や読み取り設定を変更すると、セルの読み取り値は自動で更新されます。スライダーは指を離した時、数値入力は確定した時に反映され、手動で指定したセルは保持されます。

### 格子の補正と画像変換

LM補正と曲面補正は**格子の補正**にあります。**画像の追加調整**には画像回転、射影変換、**デバッグ用入力画像をPNG保存**があります。

| 操作 | 用途 |
| --- | --- |
| **LM法で格子を補正** | Levenberg–Marquardt（LM）法による位置の補正を試します。新しい作業では有効です。補正後の格子を画像と照合してください。 |
| **曲面に合わせて格子を補正** | 曲がった紙やラベルの格子を調整します。向きを確認してから有効にし、複数の候補があれば画像に合うものを選びます。 |
| **サンプリング位置を自動微調整する** | 格子がおおむね合っているとき、セルを読み取る位置の小さなずれを探索します。処理時間が増えます。 |
| **回転・回転リセット** | 射影補正を保持したまま画像を回転します。リセットは回転角だけを0に戻します。 |
| **射影補正を解除** | 回転角を保持したまま射影補正を解除します。 |
| **選択範囲を正方形に射影補正** | 選択した範囲を正方形に変換します。Finder指定と論理セル編集は保持します。 |
| **デバッグ用入力画像をPNG保存** | 読み取りに使う画像を保存します。修復結果の画像とは異なります。 |

LM補正が有効な間は、Finderを指定し直すと補正も再計算します。四隅や向きを変更すると無効になるため、必要なら有効にし直します。セルの値や固定指定を編集しても、補正は維持されます。曲面補正と併用でき、保存した作業では選択した補正を復元します。

Finderを再指定すると、LMが無効でも指定済みの全Finderに格子を合わせ、Finder未指定の隅は固定します。画像の回転・射影補正ではLM法と曲面補正の有効設定を保持し、計算結果を再計算します。

## 4. セルを編集する

**セル編集**でセルを選び、値を指定します。

| 値 | 意味 |
| --- | --- |
| `0` | 通常の白黒の解釈では白。 |
| `1` | 通常の白黒の解釈では黒。 |
| `?` | 不明。損傷などで判断できないセルに使います。 |
| `*` | 不明のまま、修復時に0と1の両方を優先して試します。 |

**矩形範囲を選択**はドラッグで範囲を選んでから値を指定します。白・黒・不明のブラシはなぞって入力します。不明スタンプはタップした位置を中心に3×3、5×5、7×7セルを不明にします。**1セル**で1セルずつの操作に戻ります。矢印は隣のセルへの選択移動、**Undo / Redo**は編集の取り消し／再適用です。

| 編集の種類 | 効果 |
| --- | --- |
| **画像から判定** | 手動指定を取り消して画像の読み取り値を使います。 |
| **仮指定（訂正可）** | 入力した値を使いますが、修復での訂正を認めます。 |
| **固定（訂正不可）** | 初期設定では、指定した0／1に反する候補を除外します。確実な値に使います。 |

`?` と `*` は固定できません。**画像から判定**で選択セルの手動指定を解除できます。**指定セルを強調**で編集箇所を確認できます。

`*` は向きを確定した後、データと誤り訂正符号（ECC: Error Correction Code）のセルに指定できます。詳細解析の修復では上限は初期値4個、**優先探索の上限を変更**から、**優先探索のセル数上限**を4～14個に変更できます。4個なら16通り、14個なら16,384通りの組み合わせになるため、必要な箇所に絞ってください。上限を下げて指定数が超過した場合は、指定を減らしてから修復します。

TXT行列の読み込みでは、簡易自動修復が有効なら `*` の個数制限はありません。ただし、自動修復には時間・メモリーの制限があります。簡易自動修復を無効にして読み込む場合は14個までです。詳細解析で修復する際は、読み込んだ指定も含めて選択した個数上限が適用されます。

**コード語構造**を有効にすると、Dataを青、ECCを橙、分類未確定を紫で表示します。拡大すると8ビット単位のコード語の外周線を表示し、さらに拡大するとQRコード内でのコード語の並び順を表示します。セルを選択すると、ブロック・Data/ECC内の番号・ビット位置を確認できます。

セル編集の**データ**は、画面を広く使う専用表示で確認できます。マスク解除・部分情報は切り替えるだけで更新されます。**閉じる**でセル編集に戻り、編集やUndo / Redoの後に開き直すと最新の内容を表示します。

## 5. 修復して結果を確認する

**修復する**を押します。中断する場合は**修復を中断**を押し、画面の案内を確認します。途中の候補を保持できる環境もありますが、強制終了ではその実行の未確定候補は保存されません。編集内容と前回の結果は残ります。

**修復結果**で候補を切り替えます。**候補一覧**では全文検索と20件ずつのページ切り替えができます。表示する候補は最大256件で、探索中に見つかった総数とは異なることがあります。

**候補の検証情報**では、**形式情報領域**と**データ・ECC領域**それぞれについて、比較対象の既知bit数と不一致bit数を表示します。後者にはデータと誤り訂正符号の両方を含みます。比較対象は、画像の読み取りと手動編集を反映した、修復開始時の既知の `0`・`1` です。不明bitは含みません。比較できる既知bitがない領域では、一致を確認できないことを表示します。

本文は詳細を開いても表示されます。**修復の根拠**・**データ**・**探索の診断情報**はそれぞれ見出しで開閉します。再修復するときは、**画像・格子を調整**・**セルを編集**・**詳細設定で再試行**から該当する設定に戻ります。

内容欄には内容の種別と取得できた項目、修復方法の要約、文字コードや手動指定との不一致に関する注意も表示します。**内容をコピー**は説明や注意を含めず、復号された本文の全文だけをコピーします。修復方法の詳細は**修復の根拠**で確認できます。

- **QRコードの内容**：復号された全文を確認し、**内容をコピー**または**PNG保存**を選びます。PNG（Portable Network Graphics）は画像ファイル形式です。
- **QRプレビューの表示段階**：修復前・修復後・左右比較を切り替えます。別の候補との違いは**QRコードの内容 → 比較相手を選択**で確認できます。
- **修復の根拠**：セルをタップすると、補完・訂正の根拠を表示します。修復結果の画像直下にある**色と記号の説明**では、セルの値と修復理由を示す枠色を確認できます。初期状態では展開されており、見出しで折りたためます。
- **QRプレビューの同じコード語を表示**：選択したセルと同じコード語のセルを強調します。コード語は8ビットのまとまりです。
- **探索の診断情報**：試した条件や候補が得られなかった理由を確認します。候補の評価値は、正しさの確率を表しません。選択した候補の試行の完了状況と、探索全体の記録は分けて確認します。例えば候補を得た試行が完了していても、別の条件の試行は時間切れの場合があります。

**データ**では、**部分情報**がOFFのときに、データとECCのコード語を16進数（HEX）と0・1のビット列（Binary）で確認できます。不明bitは `?` で表示します。表示段階を選び、**マスク解除**・**部分情報**で表示内容を切り替えます。開いたときと設定を変えたときに自動更新します。既定は、修復成功時が**制約・RS修復後／マスク解除ON／部分情報OFF**、修復失敗時が**制約・RS修復前／マスク解除ON／部分情報ON**です。同じ結果の画面移動や言語切替では選択を保持し、新しい修復結果では既定に戻ります。部分情報は未検証の診断用データです。

詳細解析で通常の誤り訂正を超えて候補を探すリスト復号には、修復1回につき累計10分の制限があります。通常の探索時間は別なので、全体では10分を超える場合があります。

QRプレビューの**マスク解除**はデータを見やすくするための表示切り替えです。保存する修復PNGには通常のQRコードのマスクが適用されます。

候補がない場合は、バージョン、向き、四隅、誤った固定セルを見直します。**データ**は修復前にも利用できますが、部分情報は検証済みの復号結果ではありません。

**終端後の追加セグメントを解析**を開くと、通常のデータの終わりより後にある情報を調べて表示します。解析対象を確認し、必要なら生データの表示開始位置を終端直後、次のバイトの先頭、指定したビット位置から選びます。ここで表示された解釈も、検証済みの修復候補とは区別してください。

## 6. 詳細設定を選ぶ

**画像の追加調整**と**修復する**の間にある**修復の詳細設定**を開いて変更します。誤り訂正レベル・マスクなどの条件は、この項目の中で確認できます。同じ作業で画面を往復すると、開いた項目とスクロール位置を保持します。

通常は初期設定から始め、必要な項目だけ変更します。

| 設定 | 用途と注意点 |
| --- | --- |
| **誤り訂正レベル／マスク** | 分かっている場合に指定します。不明なら自動のままにします。 |
| **固定セルの0/1と矛盾する復元候補を許容する** | 固定セルも仮指定と同じく訂正可能にします。初期状態は無効です。 |
| **形式情報の誤り上限** | 誤り訂正レベルやマスクを示す情報の不一致をどこまで認めるか選びます。 |
| **データ・ECCの誤り上限** | 読み取り済みのデータ・誤り訂正セルとの不一致の上限です。 |
| **部分bit探索・自由度の上限** | 不明なビットの組み合わせを探す上限です。初期値12で、13、14へ増やすほど処理が重くなります。 |
| **既知bit誤りの追加探索** | 読み取り済みの値の誤りを最大1ビットまたは2ビットまで追加で探します。初期値はOFFです。 |
| **通常RSからの追加探索上限** | Reed–Solomon（RS）誤り訂正による通常の探索を広げます。初期値は+1コード語です。上限を上げても候補が増えるとは限りません。 |
| **バイトモードの内容を UTF-8 文字列と仮定する** | 文字コード指定のないバイト区間を、文字の符号化方式UTF-8として絞り込みます。他の文字コードや文字以外のデータが考えられる場合は無効にします。 |
| **単一セグメントの終端後構造を強制する** | 数字・英数字・バイト・漢字のいずれか1種類だけから成るデータ区間（セグメント）で、種類と長さを確定または試行できる場合に使います。複数セグメントには使わないでください。 |

誤り上限には**初期設定・完全一致・厳しめ・緩め・手動・制限なし**があります。完全一致は読み取り値との不一致を認めません。制限を緩めると処理時間や候補数が増える場合があります。

修復後に単一セグメントの仮定で再実行する案内が出た場合、**今回だけ再実行**はその実行だけに適用されます。設定欄で有効にする場合とは異なり、次の通常の修復では解除されます。

## 7. 保存、再開、出力

**メニュー → 終了**は、作業の保存完了後に画面を閉じます。端末・ブラウザーの制約で閉じられない場合は案内が表示されるので、端末のホーム画面へ戻るか、タブを閉じて終了してください。**アプリに戻る**で作業を続けられます。保存できなかった場合は終了せず、**メニュー → 現在の作業 → ファイルに書き出す**で保存してください。

変更はこのブラウザーに自動保存されます。**メニュー → 保存した作業を開く**から再開・削除できます。最大20作業、各作業40状態の履歴を保持し、上限を超えると古いものから削除します。**メニュー → 現在の作業 → 操作履歴**から以前の状態を選べます。自動修復の結果を再開するときも、その結果に使われた実行条件を保持します。

**メニュー → 現在の作業**から保存・復帰・ファイル出力を行います。**保存**は戻り先を記録します。その後に編集しても、**保存状態へ戻す**で保存時の状態へ戻せます。

| 出力 | 保存する内容・用途 |
| --- | --- |
| **ファイルに書き出す**（`.qrpwa`） | 作業、設定、履歴、元画像をまとめて保存します。別端末への移動やバックアップに使います。読み込み上限は32メビバイト（MiB、約34メガバイト）です。 |
| **Android互換のQRRを書き出す**（`.qrr`） | Android版QRevyの保存形式に対応するファイルです。元画像は含まれません。形式の版番号23～42を読み込み、42で書き出します。 |
| **修復前のTXT行列を保存**（`.txt`） | 編集済みの入力セル値をテキストとして保存します。画像、編集の種類、履歴は含まれません。 |
| **PNG保存**（`.png`） | 選択中の候補をQRコード画像として保存・共有します。作業を再開するための形式ではありません。 |

Android版QRevyの標準画面にはQRRファイルの読み込み・書き出し機能はありません。

QRRに画像が必要な場合は**QRRの元画像を追加**で対応する画像を選び、四隅と向きを確認します。別の画像を取り違えないよう注意してください。共有先や保存先の選択画面は端末・ブラウザーによって異なります。

作業は端末間や別のブラウザー、別の配信アドレスとは同期しません。移動には `.qrpwa` の書き出しと読み込みを使います。ブラウザーのデータ削除や空き容量不足で作業が消える場合があるため、重要な作業はファイルにも保存してください。

写真やQRコードの内容は端末内で処理します。ファイルやコピーした内容の扱いは、保存先・共有先の設定にも依存します。詳しくは[プライバシー](../PRIVACY.ja.md)を参照してください。
