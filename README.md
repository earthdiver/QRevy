# QR Repair

[English](README.en.md) | 日本語

QR Repairは、通常のQRリーダーでは読み取れない損傷したQR Code Model 2を、端末上で解析・修復するAndroidアプリです。画像の状態を確認しながら、位置、濃淡、位置検出パターン、セルを手動で補助でき、復元結果の根拠も確認できます。

修復結果の正しさを保証するものではありません。重要な内容は、必ず別の手段でも確認してください。

UIでは、位置検出パターンを「Finder」、モジュールを「セル」、形式情報を「形式」と短く表示する場合があります。

文書の本文では「ビット」「モジュール」「コード語」「ECCレベル」「マスク」を使います。UI名・表示例・ソース識別子は原表記を維持します。UIの「セル」はモジュール、「Codeword」はコード語、「Finder」は位置検出パターンに対応します。

## 主な機能

- 画像ファイルの読み込みとカメラ撮影
- `0 / 1 / ? / *`だけで構成されたQR行列テキストの読み込み
- 回転、クロップ、四隅、濃淡、QRバージョンの調整
- 位置検出パターンの役割の手動指定と指定位置の局所補正
- `0 / 1 / ? / *`によるセル編集とUndo／Redo
- QR構造と誤り訂正を利用した修復
- Binary、HEX、復号内容の確認
- 復号不能時のモード・文字数（`mode／count`）と、数字・英数字・バイト・漢字モードで先頭から連続して確定した内容の部分情報表示
- セル単位の修復理由と同じコード語の表示
- 修復結果の画像保存
- 作業履歴とセッション保存
- インターネット接続を使用しない端末内処理

対応対象はQR Code Model 2のバージョン1～40です。Model 1、Micro QR、rMQRには対応していません。

## 使い方

1. 画像を読み込むか、カメラで撮影します。`0 / 1 / ? / *`のQR行列テキストを読み込むこともできます。
2. 必要に応じて画像を回転し、QRの範囲をクロップします。
3. 自動推定された四隅、バージョン、2峰／3峰の濃淡を確認し、必要なら調整します。色付き不明領域を使う場合は基本設定でONにできます（初期値はOFF）。
4. QRの向きが違う場合は、位置検出パターンの左上・右上・左下の役割を手動指定します。
5. 必要なら詳細設定でセルや探索条件を調整します。
6. 修復を開始し、復号内容とセルの修復理由を確認します。

セル編集の「手動指定にする／画像に戻す」で、選択セルの由来を切り替えられます。同じ0/1を押しただけでは手動指定になりません。一度変更した値は手動指定として残るため、誤操作を取り消して画像由来へ戻す場合は「画像に戻す」またはUndoを使います。ボタンの近くで現在の由来・値と、現在の画像調整設定から読み取る値を確認できます。複数セルの選択にも対応しています。通常のセル編集画面（5倍表示を含む）と拡大セル編集画面では、水色の四角が手動指定、黄色の丸が選択中を示します。値が画像と同じ場合や選択中でも、手動指定の印は表示されます。

内部の探索順序、制約、Reed–Solomon処理、候補の検証方法は[修復戦略](docs/RECOVERY_STRATEGY.ja.md)にまとめています。

メニューの「画面スタイル（次回起動時）」からクラッシック／モダンを選択して保存できます。初期設定はクラッシックです。変更はアプリを終了して次回起動したときに反映され、再度変更するまで維持されます。画面回転や言語変更では適用中のスタイルを維持します。モダンはダーク背景とライム色のアクセント、書体を整えた「QR Repair」タイトルを使います。

モダン画面では、ホームから過去の作業を再開でき、「01 修復設定」「02 セル編集」「03 修復結果」のタブで移動できます。03は結果がある場合に有効になり、タブを往復しても未保存の編集とUndo履歴を保持します。修復設定・セル編集の下部には「ホーム」「画面切替」「データ」「保存」「修復」があり、「保存」は修復せず保存、「修復」は保存後に修復を実行します。未保存の変更がある状態でホームへ戻る場合は確認します。画像未読込時の「作業画面」では取り込み方法を選びます。画像領域は正方形で、手動指定の操作欄はブラシの下にまとめています。「手動指定セルだけ強調」は表示だけを切り替え、判定件数や編集履歴は変わりません。拡大編集の回数表示とUndo・Redo・閉じるは画面下部に固定しています。データは共通のポップアップで表示し、結果画面では「詳細結果を表示」から修復根拠を確認できます。保存した作業は「作業一覧」、現在の編集の経過は「操作履歴」から確認します。

## ローカルビルド

必要環境:

- JDK 17
- Android SDK（compile/target SDK 37）
- Android API 26以上

```bash
bash bootstrap-wrapper.sh
bash scripts/verify-wrapper.sh
./gradlew :shared:jvmTest
./gradlew :androidApp:testDebugUnitTest :androidApp:lint :androidApp:assembleDebug
```

debug APKは`build/androidApp/outputs/apk/debug/androidApp-debug.apk`に生成されます。

公開用application IDは`io.github.earthdiver.qrrepair`です。リリース署名、ストア識別子、公開Privacy Policy URLはリポジトリに含まれていません。公開前の確認については[リリースチェックリスト](docs/RELEASE_CHECKLIST.md)を参照してください。
