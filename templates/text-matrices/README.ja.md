# QRテキスト行列テンプレート

QR Repairで読み込める、QR Code Model 2のバージョン1～40のテンプレートです。
必要なバージョンの `version-NN.txt` を選んでください。一辺のセル数は `17 + 4 × バージョン`（21～177）です。

- `0`：白セル。
- `1`：黒セル。
- `?`：不明セル。読み取れた箇所を `0` または `1` に置き換えてください。

位置検出パターン、分離パターン、タイミングパターン、位置合わせパターン、固定暗モジュール、バージョン情報（バージョン7～40）は記入済みです。
形式情報の両コピーと、誤り訂正コード語・残余ビットを含むデータ領域全体は `?` です。残余ビットも未確定のマスクに依存します。

左上・右上・左下に位置検出パターンがある標準の向きで、行は上から下、列は左から右です。TXTファイルにクワイエットゾーン、見出し、空白は含まず、末尾にはLF改行が1つあります。編集時も正方行列の形を維持してください。未編集のテンプレートだけではペイロードを復元できません。

既存の依存ライブラリZXing Core 3.5.4の固定パターン・バージョン情報配置を使用して生成しました。全40ファイルの寸法・使用文字・機能領域の既知／不明セル配置を検証し、固定セルすべてを4種類の誤り訂正レベル×8種類のマスク（合計1,280シンボル）と照合しました。
