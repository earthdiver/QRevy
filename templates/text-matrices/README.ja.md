# テキスト行列テンプレート

[English](README.md) | 日本語

損傷したQRコードのセルを手作業で転記し、QR Repairに読み込むためのテンプレートです。

1. QRコードのバージョン（1～40）に合う`version-NN.txt`を選びます。たとえば、バージョン3には29 × 29セルの[version-03.txt](version-03.txt)を使います。一辺のセル数は`17 + 4 × バージョン`です。
2. 3つの四角い位置検出パターン（Finder）が左上・右上・左下に来る向きにQRコードを合わせます。行は上から下、各行のセルは左から右へ転記します。
3. 読み取れるセルの`?`を`0`または`1`に置き換えます。判断できないセルは`?`のままにします。
4. ファイルを保存し、QR Repairの「テキスト行列を読み込む」で開きます。向きを確認し、Finderの役割が自動設定されなかった場合は、修復前設定で少なくとも1つ指定してください。操作は[ユーザーガイド](../../docs/USER_GUIDE.ja.md)を参照してください。

| 文字 | 意味 |
| --- | --- |
| `0` | 白いセル |
| `1` | 黒いセル |
| `?` | 不明なセル |
| `*` | 優先探索に指定した不明なセル。指定できるセルと上限はユーザーガイドを参照 |

選択したバージョンで値が決まるパターンは記入済みです。形式情報と、誤り訂正用のデータを含むデータ領域は、QRコードによって値が変わるため`?`にしています。テンプレートだけでは内容を復元できません。読み取れるセルを記入してから使ってください。

行数と各行の文字数は変えないでください。使えるのは上の4文字と改行だけです。空白、見出し、空行、QRコードの周囲の白い余白（クワイエットゾーン）は含めません。改行はUnix形式（LF）またはWindows形式（CRLF）を使い、末尾の改行は1つまでにしてください。
