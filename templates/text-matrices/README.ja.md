# QRテキスト行列テンプレート

[English](README.md) | 日本語

QR Repairで読み込める、QR Code Model 2のバージョン1～40のテンプレートです。
復元したいQRコードと同じバージョンの `version-NN.txt` を選んでください。一辺のセル数は `17 + 4 × バージョン`（21～177）です。

1文字が1セルに対応します。

- `0`：白セル。
- `1`：黒セル。
- `?`：不明セル。読み取れた箇所を `0` または `1` に置き換え、判断できない箇所は `?` のままにしてください。

QRの構造から値が決まる位置検出パターン（Finder）、分離パターン、タイミングパターン、位置合わせパターン（バージョン2以上）、固定暗モジュール、バージョン情報（バージョン7以上）は、あらかじめ記入しています。
一方、形式情報の両コピーと、誤り訂正コード語・残余ビットを含むデータ領域全体は、対象のQRコードによって値が変わるため `?` にしています。残余ビットもマスクによって値が変わるため、ここに含めています。
テンプレートにはQRの内容を表すデータがまだないため、そのままでは内容を復元できません。読み取れた値を記入してから使用してください。

テンプレートは、Finderが左上・右上・左下にある向きで配置されています。行は上から下、列は左から右に対応するので、対象のQRコードもこの向きに合わせてから転記してください。

TXTファイルにはQRコードのセルだけが含まれ、周囲の白い余白（クワイエットゾーン）は含まれません。編集時は行数と各行の文字数を保ち、見出しや空白を加えないでください。配布ファイルの末尾にはLF改行が1つあります。記入したファイルは、QR Repairの「テキスト行列を読み込む」から取り込めます。

取り込み時は、3つのFinder、その周囲の分離パターン、縦横のタイミングパターンを4方向で照合します。各模様について、不明セルを含む全セル数に対して読み取れたセルが一定割合以上あり、誤りが許容範囲内で、他の向きより明確に一致する場合に、Finderの役割（左上・右上・左下）と向きを自動設定します。

根拠が不足していたり、向きが曖昧だったりして自動設定されなかった場合は、Finderの役割と向きが未確定のままになります。その場合は、修復前設定でFinderの役割を手動指定してください。操作の詳細は[ユーザーガイド](../../docs/USER_GUIDE.ja.md)を参照してください。

テンプレートの生成には、既存の依存ライブラリZXing Core 3.5.4の固定パターン・バージョン情報配置を使用しています。全40ファイルについて、寸法・使用文字・機能領域の既知／不明セル配置を検証しました。また、記入済みのセルが誤り訂正レベルやマスクによらず一致することを確認するため、各バージョンで4種類の誤り訂正レベルと8種類のマスクを組み合わせた合計1,280シンボルと照合しました。
